* orquestração do processo de extração, tratamento e carga dos dados brutos do censo demográfico brasileiro de 2010

Este arquivo -- =etl.org= -- é a base de geração dos códigos nas linguagens *shell* e *GNU R* usadas no tratamento das informações dos microdados.

Arquivos com extensão *.org* correspondem ao modo Org no editor de texto GNU Emacs.

Em cada bloco de código a seguir pode haver a opção denominada *tangle*, que é responsável por realizar a exportação do conteúdo dos scripts em arquivos locais.
Blocos de código na linguagem *shell* são exportados no arquivo =./etl.sh= que é o script que orquestra a totalidade dos passos necessários para baixar, tratar e disponibilizar os microdados e o dicionário de variáveis.

O comando tangle no editor GNU Emacs pode ser executado com a combinação de teclas =C-c C-v t=, que equivale a executar o comando =org-babel-tangle=.

#+begin_src sh
fetch_microdata(){

    for uf in AC AL AM AP BA CE DF ES GO MA MG MS MT PA PB PE PI PR RJ RN RO SC SE SP1 SP2_RM TO; do

        echo "Baixando os microdados de $mdata_url/$uf.zip..."
        R --quiet --vanilla -e "curl::curl_download( '${mdata_url}/$uf.zip', '${raw_data}/$uf.zip' )"

        echo 'Descompactando os microdados do arquivo $uf.zip...'
        unzip ${raw_data}/$uf.zip -d ${raw_data}

        echo 'Removendo da pasta temporária o arquivo compactado $uf.zip...'
        rm -rf ${raw_data}/$uf.zip

    done

}

* entendimento do dicionário de variáveis

A coluna =tipo= assume valores =A=, =C= e =N=.

Ao que tudo indica,
- =A= refere-se aos dados auxiliares, disponíveis em outros arquivos presentes no arquivo compactado =Documentacao.zip=, para variáveis como /área de ponderação/, /código de municípios/, /códigos de cursos superiores (graduação, mestrado e doutorado)/ entre outras.
- =C= refere-se aos dados categóricos, para os quais o dicionário de variáveis está disponível diretamente no layout (arquivo excel)
- =N= refere-se provavelmente aos dados numéricos, para os quais não é necessário um dicionário de variáveis já que a variável está pronta para uso, sendo somente necessário convertê-la para o tipo de dados (inteiro, data, número decimal, etc...) necessário para análises

O bloco de código a seguir em linguagem GNR R não é exportado (tangle) nem executado pois presta-se unicamente ao entendimento de como funciona o dicionário de variáveis do censo.

#+begin_src R :tangle ./gnur_vdict_understanding.R
## entendimento do dicionário de variáveis do censo demográfico brasileiro de 2010 (br_ibge_censo_2010)

library(readxl)   # read_excel
library(dplyr)    # mutate, transmute, filter, rename, bind_rows, arrange
library(stringr)  # str_split, str_to_lower, str_trim, str_locate
library(tidyr)    # unnest
library(glue)     # glue
library(readr)    # write_delim

src_dir <- '/tmp/etl/br_ibge_censo_2010/'
raw_data <- paste0(src_dir, 'raw/')
proc_data <- paste0(src_dir, 'data/')

vdict <-
  bind_rows( # Agregação dos dicionários de variáveis de cada base do censo
    read_excel(    # Dicionário de variáveis dos microdados de Domicílios
      path = paste0(raw_data, 'DocumentaЗ╞o/Layout/Layout_microdados_Amostra.xls'),
      sheet = 'DOMI', range = 'A3:L78', col_types = 'text', col_names = FALSE )
    %>% mutate(base = 'domi'),
    read_excel(    # Dicionário de variáveis dos microdados de Pessoas
      path = paste0(raw_data, 'DocumentaЗ╞o/Layout/Layout_microdados_Amostra.xls'),
      sheet = 'PESS', range = 'A3:L246', col_types = 'text', col_names = FALSE )
    %>% mutate(base = 'pess'),
    read_excel(    # Dicionário de variáveis dos microdados de Emigração
      path = paste0(raw_data, 'DocumentaЗ╞o/Layout/Layout_microdados_Amostra.xls'),
      sheet = 'EMIG', range = 'A3:L21', col_types = 'text', col_names = FALSE )
    %>% mutate(base = 'emig'),
    read_excel(    # Dicionário de variáveis dos microdados de Mortalidade
      path = paste0(raw_data, 'DocumentaЗ╞o/Layout/Layout_microdados_Amostra.xls'),
      sheet = 'MORT', range = 'A3:L21', col_types = 'text', col_names = FALSE )
    %>% mutate(base = 'mort')
  ) %>%
  rename( # Troca dos nomes de colunas
    var = 1, desc = 2, pos_ini = 8, pos_fin = 9, len = 10, dec = 11, tipo = 12
  ) %>%
  select( # seleção somente das colunas necessárias para análise
    base, var, desc, pos_ini, pos_fin, len, dec, tipo
  )


## tipo == A
##      refere-se a dados auxiliares, disponíveis em outros arquivos
##      presentes no arquivo compactado =Documentacao.zip=, para
##      variáveis como área de ponderação, código de municípios,
##      códigos de cursos superiores (graduação, mestrado e doutorado)
##      entre outras.
vdict %>%
  filter(
    grepl(pattern = 'a', tipo, ignore.case = TRUE)
  ) %>%
  arrange(var) %>%
  View

## tipo == C
##      refere-se aos dados categóricos, para os quais o dicionário
##      de variáveis está disponível diretamente no layout
##      (arquivo excel)
vdict %>%
  filter(
    grepl(pattern = 'c', tipo, ignore.case = TRUE)
  ) %>%
  arrange(var) %>%
  View

## tipo == N
##      refere-se provavelmente aos dados numéricos, para os quais
##      não é necessário um dicionário de variáveis já que a variável
##      está pronta para uso, sendo somente necessário convertê-la
##      para o tipo de dados (inteiro, data, número decimal, etc...)
##      necessário para análises
vdict %>%
  filter(
    grepl(pattern = 'n', tipo, ignore.case = TRUE)
  ) %>%
  arrange(var) %>%
  View


## tipo == C
##      Observações:
##        1. variáveis do tipo C no dicionário de variáveis trazem,
##           na grande maioria dos casos, os códigos e as respostas
##           por escrito dentro de uma mesma célula, com quebras de
##           linha -- caracter \n -- no conteúdo da célula.
##        2. é necessário portanto tratar os dados para separar o
##           enunciado da questão do censo, geralmente a primeira
##           na célula, da lista de respostas (código e resposta por
##           escrito).
##        3. o código a seguir gera o conteúdo, ou corpo, da função
##           tribble que traz o dicionário de variáveis tratado
##           para todas as variáveis do tipo =C=
vdict %>%
  filter(
    grepl(pattern = 'c', tipo, ignore.case = TRUE)
  ) %>% 
  transmute(
    ## converte 'var' para somente letras minúsculas
    var = str_to_lower(var),
    ## cria, na coluna 'answer', a lista formada pelos conteúdos
    ## entre as quebras de linha \n presentes dentro da célula da
    ## coluna 'desc'
    answer = str_split( string = desc, pattern='\n') # 
  ) %>%
  ## cada conteúdo entre as quebras de linha \n nas células da
  ## coluna 'answer' torna-se uma linha própria e repete o
  ## conteúdo da coluna 'var'
  unnest(answer) %>%
  ## o conjunto de alterações a seguir precisa ocorrer no nível
  ## das linhas da tabela, por isso é necessário explicitamente
  ## chamar o comando rowwise()
  rowwise() %>%
  ## tratamento das respostas de questões do tipo =C=
  mutate(
    ## as respostas têm o código e o conteúdo por escrito
    ## separados pelo hífen, então a coluna 'sep' traz a posição
    ## do caracter '-' no string contida na coluna 'answer'
    ## exemplo: se o conteúdo de 'answer' fosse
    ##   "01 - teste"
    ## a função str_locate( string = answer, pattern = '-')[1]
    ## retorna 4, pois o hífen está na quarta posição
    sep = str_locate( string = answer, pattern = '-')[1],
    ## a_code, o código da resposta, está antes do hífen
    a_code = substr(answer, start = 1, stop = sep-1 ),
    ## e a_desc, a resposta por escrito, depois do hífen
    a_desc = substr(answer, start = sep + 1, stop = str_length(answer)),
    ## remove espaços redundantes de ambas as novas variáveis
    ## tratadas 'a_code' e 'a_desc'
    a_code = str_trim(a_code),
    a_desc = str_trim(a_desc)
  ) %>%
  ## NAs são introduzidos geralmente nas linhas de enunciados
  ## da pergunta já que elas não contém o caracter '-' separando
  ## código e resposta por escrito.
  ## essas linhas são portanto ignoradas com o comando na.omit()
  na.omit() %>%
  ## com os dados tratados, o corpo da função tribble, contendo
  ## as colunas 'var', 'a_code' e 'a_desc' é construído seguindo
  ## o padrão
  ##      'var', 'a_code', 'a_desc',
  transmute(
    res = glue("'{var}',     '{a_code}', '{a_desc}',")
  ) %>%
  ## e escrito em disco, como arquivo de texte delimitado por
  ## pipe, caracter '|', para uso posterior diretamente na longa
  ## seção de variáveis tratadas do tipo =C=
  write_delim(
    file = glue('{src_dir}/data/typeC_tribble_bodies.txt'),
    quote = 'none',
    delim = '|'
  )
#+end_src

prepare_microdata_for_data_ingestion(){

    echo 'Transforming microdata from fixed width format to delimited file...'

    # 'characters' argument from 'cut' function
    CHARACTERS_ARG=$(cat ${proc_data}/cut_characters_argument.txt)

    # from fixed width format to pipe (|) delimited text file
    cut \
        --output-delimiter='|' \
        --characters=$CHARACTERS_ARG \
        ${raw_data}/PNADC_2022_trimestre3.txt > \
        ${proc_data}/microdata.txt

    echo 'DONE.'
}
